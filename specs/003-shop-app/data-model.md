# Data Model: Shop Application (003)

Money is stored as **integer cents** of mUSDT (`price 15.00` → `1500`) in both stores. Ids are
UUIDv7 strings generated by the app. Times are UTC.

## Entities

### Item

| Field | Type | Rules |
|-------|------|-------|
| `id` | UUIDv7 | generated |
| `name` | string | trimmed, 1–100 chars; unique per shop ignoring case (`nameKey = lower(name)`) |
| `stock` | int | ≥ 0 |
| `priceCents` | int64 | ≥ 1; entry allows at most 2 decimals |
| `createdAt`, `updatedAt` | timestamp | set by the store |

`available` = `stock > 0` (FR-012). Deleting an item never touches orders (FR-003).

### Order

| Field | Type | Rules |
|-------|------|-------|
| `reference` | string | 10 chars of Crockford base32 from a CSPRNG; unique (retry on collision) |
| `createdAt` | timestamp | |
| `status` | enum | `PendingPayment` only in this feature (spec 005 adds the rest) |
| `walletAddress` | string | `WALLET_ADDRESS` at ordering time (spec edge case: wallet switch) |
| `totalCents` | int64 | sum of the lines |
| `lines` | list of OrderLine | 1–50 lines |

### OrderLine (value, stored inside the order)

| Field | Type | Rules |
|-------|------|-------|
| `itemId` | UUID | may no longer exist |
| `name` | string | snapshot at ordering time |
| `unitPriceCents` | int64 | snapshot; must equal the current price when ordering (FR-013) |
| `quantity` | int | 1 – current stock |

### Admin (exactly one record)

| Field | Type | Rules |
|-------|------|-------|
| `passwordHash` | string | `PasswordHasher` v3 (PBKDF2) |
| `initial` | bool | `true` while the operator-generated password is in use (research R11) |
| `changedAt` | timestamp? | set on password change |
| `failedCount`, `failedWindowStart` | int, timestamp? | 5 within 15 min → lock |
| `lockedUntil` | timestamp? | sign-in refused until then, even with the right password |

### Data-Protection key

`name` → XML (written by ASP.NET Core). Shared by all replicas (research R11).

### Cart (browser only)

`localStorage["shop.cart"]` = `[{itemId, name, unitPriceCents, quantity}]`. Never sent to the
backend except as the order request.

## State transitions

```text
Order:  (placed) ──▶ PendingPayment          # this feature ends here; 005 adds Paid/Expired
Admin.initial: true ──(password change)──▶ false   # never back to true
Admin lock: open ──5 failures/15 min──▶ locked ──15 min──▶ open (counter reset)
```

## PostgreSQL layout (`PostgresShopStore`)

```text
schema_version(version int primary key, applied_at timestamptz)
items(id uuid pk, name text, name_key text unique, stock int check (stock >= 0),
      price_cents bigint check (price_cents > 0), created_at, updated_at)
orders(reference text pk, created_at timestamptz, status text, wallet_address text,
       total_cents bigint, lines jsonb)            -- index on created_at desc
admin(id smallint pk check (id = 1), password_hash text, initial bool, changed_at,
      failed_count int, failed_window_start, locked_until)
dp_keys(name text pk, xml text)
```

Search: `WHERE name ILIKE '%' || @q || '%' ESCAPE '\'`, with `%`, `_` and `\` in the input
escaped.

## Redis layout (`RedisShopStore`)

| Key | Type | Content |
|-----|------|---------|
| `shop:schema` | string | schema version |
| `shop:lock:init` | string | init lock (`NX PX 30000`) |
| `shop:items` | hash | `id` → item JSON |
| `shop:item-names` | hash | `nameKey` → `id` (uniqueness, kept in step by Lua) |
| `shop:order:{reference}` | string | order JSON |
| `shop:orders` | sorted set | `reference`, score = `createdAt` ms (newest first via `ZREVRANGE`) |
| `shop:admin` | hash | admin fields |
| `shop:dpkeys` | hash | `name` → XML |

- Item create, rename and delete run as Lua scripts, so `shop:items` and `shop:item-names` stay
  consistent.
- Search loads `shop:items` (≤ 1,000 entries, one `HGETALL`) and filters in the app.
- Order placement is a single Lua script (research R9).
